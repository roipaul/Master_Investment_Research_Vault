# Data

Files kept apart from the notes.

- `screens/` — monthly screen exports (Capital IQ), named `YYYY-MM_<screen-name>.xlsx`. Keep every month, so history survives if access changes.
- `consensus/` — Visible Alpha exports used for the "sell-side consensus" column, named `YYYY-MM-DD_<TICKER>.xlsx`.

Notes may cite a file here, but never paste its contents in.
