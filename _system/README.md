# System: the research process, kept apart from the research

This folder holds copies of how the research is done. It holds no research. The research skills do not read or write here.

- `skills/` — a snapshot of the twenty research skills as saved in Claude on the copy date: each skill's `SKILL.md`, plus the full-primer skill's build script and section spec.
- `memory/` — copies of Claude's memory notes on the research process and on this vault.

These are backups. The live skills and the live memory are in Claude, and a change made there does not appear here until the copy is refreshed. Editing a file here changes nothing in Claude.
