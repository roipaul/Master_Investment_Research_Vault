# Skill freeze and test log

**The rule (Paul, 2026-11-27).** No new research skill is built. Existing skills may be edited. The freeze on a skill's neighbours lifts only when each new skill has run on two or three names. After that, any skill that has not changed a decision is a candidate to cut; Paul decides.

**What counts as a run.** One company (or one cycle note or market) taken through the skill, with the output filed in the vault. Work done in Projects before the vault existed is not counted here.

**How this file is kept.** Counts are taken from the files in the vault. "Changed a decision?" is filled only from what Paul says or records; it is left blank otherwise.
