# Master Investment Research Vault

Private research notes for Paul's investment work. Everything is plain markdown, so the folder opens as an Obsidian vault. Claude's research skills read and write here through the `research-kb` skill, and `research-flow` tracks where each name stands.

## Three rules

1. **Notes hold judgments, not data.** Prices and time series live elsewhere. Any number in a note carries its date and its source.
2. **Append, never rewrite.** Updates are added as dated sections or dated log lines. Earlier entries stay as they were written.
3. **Data stays apart from notes.** Screen exports and other files go under `data/`, never inside a note.

## Conventions

- Every note starts with frontmatter. Templates are in `_templates/`.
- Link the first mention of a company, theme, policy, entity or person with `[[...]]`.
- Commit messages: `<TICKER>: <skill> <date> — <one line>`.
- Commits go straight to `main`. This is a notes vault, not code, so there are no branches or pull requests.
