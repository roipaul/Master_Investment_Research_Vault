# Uploads for the earnings watch

When the earnings watch cannot reach a company's results documents or call transcript, it pauses and asks for them. Put the files in a folder named for the ticker as it appears in `monitoring.md`, for example `inbox/uploads/0700-HK/`. The next daily run reads them and writes the update.

- Name each file so the period is clear, for example `Q3-2026 transcript.pdf`.
- The watch reads these files; it does not copy their text into notes.
- Clear a folder out once its update is written.
