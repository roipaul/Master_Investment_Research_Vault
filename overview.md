# Research overview

Every company with work in the vault, grouped by where it stands, with the prices that matter. This is a view: `/research-flow overview` rebuilds it from the hubs, [[watchlist]], [[buylist]] and [[price-alone-basket]], so change those, not this file.

How a name moves: research → **watchlist** (Paul decides to watch it; `/decision-record TICKER watch`) → **buy list** (enough work done; Paul sets a buy price with `/decision-record TICKER buy-list <price>`) → a recorded initiate, or back off the list (`unlist`, or `pass`). The price watch notifies Paul when a buy-list name reaches its buy price.

**Two kinds of price below.** A *buy price* is Paul's own and only exists on the buy list. A *reference entry level* is Claude's arithmetic from the work on file (the price at which a named case clears the 15% hurdle); it is an input for Paul's decision, never a buy price.
